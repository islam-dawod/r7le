# رحلة R7LE — الموقع الإلكتروني (R7LE.COM)

منصّة عراقية مستقلة لخدمات **المساعدة الإدارية وتجهيز وتنظيم مستندات طلب التأشيرة**
لوجهات **أمريكا وكندا وأستراليا** — موجّهة للجمهور العراقي، باللغة العربية (RTL)،
بتصميم Mobile‑first.

> **إفصاح:** رحلة R7LE علامة تجارية لخدمات خاصة ومحددة. لسنا سفارة أو قنصلية أو جهة
> حكومية، ولسنا تابعين لسلطات الهجرة الأمريكية أو الكندية أو الأسترالية. لا تضمن
> خدماتنا قبول أي تأشيرة أو سرعة قرارها.

يُبنى هذا المستودع وفق وثيقة المواصفات `R7LE_Complete_Website_Instructions_Iraq.pdf`.

## ما الذي أُنجز في هذه المرحلة

الواجهة العامة الكاملة للموقع (المرحلتان 1 و2 من خطة التنفيذ): خريطة الموقع بالكامل،
الهوية البصرية، المحتوى العربي الأساسي، الصفحات القانونية والإفصاحات، وكتالوج الخدمات —
كموقع ثابت (Static) قابل للاستضافة مباشرة.

> الأجزاء التي تتطلب خادمًا (بوابة الدفع، إنشاء الطلبات بعد التحقق الخادمي، لوحة الموظفين،
> قواعد البيانات، MFA) تُبنى ضمن **المرحلة 3 (المعاملات)**؛ واجهات العميل هنا تمهيدية للعرض.

## البنية

```
.
├── index.html + مجلد لكل مسار (index.html)   # صفحات ثابتة جاهزة للاستضافة
├── assets/css/styles.css                      # نظام تصميم RTL، Mobile-first
├── assets/js/main.js                          # قائمة الجوال + أكورديون الأسئلة
├── assets/img/favicon.svg
├── robots.txt · sitemap.xml · .nojekyll        # SEO واستضافة GitHub Pages
└── build/build.py                             # مولّد الموقع (مصدر الحقيقة للصفحات)
```

الصفحات **مُولَّدة** عبر `build/build.py` لضمان اتساق الهيدر/الفوتر/الإفصاح عبر كل الصفحات.

### إعادة البناء
```bash
python build/build.py
```

### معاينة محلية
```bash
python -m http.server 8000
# افتح http://localhost:8000/
```

## قرارات مطلوبة من مالك المشروع قبل الإطلاق (القسم 16)

الحقول المعلّمة بـ **«قيد التأكيد»** في الموقع (الكيان القانوني، رقم التسجيل، العنوان،
رقم/بريد الدعم، ساعات العمل، رابط واتساب) يجب تثبيتها قبل الإطلاق. كذلك: اعتماد قائمة
الخدمات الحقيقية المسموح بها قانونيًا، الأسعار والعملات وسياسة الاسترداد الواقعية،
اختيار بوابة دفع تقبل النشاط، ومزوّد الاستضافة وسياسة تخزين/حذف المستندات.

## ملاحظات امتثال (مهمة)

- لا 301/Redirect/Canonical نحو المواقع المرجعية (USAGCD / CANADAV / AUSTRALIAV)؛ نطاق مستقل.
- لا تفعيل زر شراء لأي خدمة فيها تقييم أهلية أو تمثيل قبل المراجعة القانونية.
- فصل واضح بين «موقع قابل للفحص» و«حملة إعلانية مسموح تشغيلها بعد التحقق» (سياسة Google Ads).
- لا إرسال بيانات حساسة (أرقام جوازات/محتوى نماذج) إلى أدوات التحليلات أو الإعلانات.
